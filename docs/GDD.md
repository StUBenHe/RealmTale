## 1. 游戏概述

### 1.1 一句话描述
**RealmTale（王国物语）**是一款中世纪奇幻模拟经营游戏，玩家在龙与地下城的世界中建造城市、招募英雄、探索地下城，打造属于自己的王国。

### 1.2 核心卖点
- 🏰 **深度建造**：50+ 种中世纪建筑，从农舍到龙巢
- ⚔️ **英雄收集**：D&D 风格职业系统（战士/法师/盗贼/牧师）
- 🐉 **奇幻世界**：龙、精灵、矮人、地精等经典奇幻种族
- 🌐 **三端互通**：手机/电脑随时随地管理你的王国

### 1.3 目标用户
- 年龄：16-35
- 喜欢模拟经营 + 策略类游戏
- 对中世纪/奇幻/D&D 世界观感兴趣的玩家
- 国内 + 海外双市场

### 1.4 竞品分析

| 游戏 | 优势 | 我们的差异化 |
|------|------|-------------|
| 江南百景图 | 国风美学、文化共鸣 | 欧洲奇幻、D&D 深度 |
| 迷你世界 | UGC、社交强 | 经营深度、英雄系统 |
| Travian | 经典策略 | 画面更精致、上手更简单 |
| Forge of Empires | 成熟产品 | 更轻量、更休闲 |

## 2. 核心玩法

### 2.1 游戏循环

```
         ┌──────────────────────────────┐
         │                              │
         ▼                              │
    ┌─────────┐    ┌─────────┐    ┌─────┴─────┐
    │  建造    │───▶│  生产    │───▶│  收集/出售 │
    └─────────┘    └─────────┘    └─────┬─────┘
         ▲                              │
         │                              ▼
    ┌────┴─────┐              ┌─────────┐
    │  升级    │◀─────────────│  购买    │
    └──────────┘              └─────────┘
```

### 2.2 建造系统

| 建筑类型 | 功能 | 解锁条件 |
|----------|------|----------|
| 🏠 农舍 | 产出金币 + 人口 | 初始 |
| 🪵 伐木场 | 产出木材 | Lv2 |
| ⛏️ 矿场 | 产出铁矿 | Lv3 |
| 🧪 炼金坊 | 产出药水 | Lv5 |
| ⚔️ 铁匠铺 | 消耗铁矿，产出武器 | Lv5 |
| 📚 魔法学院 | 产出魔法卷轴 | Lv8 |
| 🐉 龙巢 | 特殊加成 + 探索入口 | Lv10 |
| ⛪ 教堂 | 民心加成 | Lv4 |
| 🏪 集市 | 交易资源 | Lv6 |
| 🏰 城堡 | 主城，解锁高级功能 | Lv15 |

### 2.3 英雄系统

#### 职业（4 基础 + 4 进阶）

| 基础职业 | 进阶职业 | 特色能力 |
|----------|----------|----------|
| ⚔️ 战士 | 🛡️ 圣骑士 | 建筑防御 +20% |
| 🧙 法师 | 🔮 大法师 | 魔法产出 +30% |
| 🗡️ 盗贼 | 🌙 暗影刺客 | 探索收益 +25% |
| 💫 牧师 | ✨ 贤者 | 人口增长 +15% |

#### 英雄属性
- **品质**：普通（白）→ 稀有（蓝）→ 史诗（紫）→ 传说（金）
- **技能**：每个英雄有 2 个被动 + 1 个主动技能
- **好感度**：使用越多，好感越高，解锁专属剧情

### 2.4 资源系统

| 资源 | 获取方式 | 用途 |
|------|----------|------|
| 🪙 金币 | 建筑产出、出售商品 | 建造、升级、购买 |
| 🪵 木材 | 伐木场 | 建造建筑 |
| ⛏️ 铁矿 | 矿场 | 建造高级建筑、锻造 |
| 🧪 药水 | 炼金坊 | 英雄恢复、探索 |
| 📜 卷轴 | 魔法学院 | 英雄升级、特殊建筑 |
| 💎 魔晶 | 探索/任务 | 高级购买、英雄招募 |

### 2.5 探索系统（Phase 2+）

- 地下城：回合制自动战斗
- 野外探索：派遣英雄，自动探索获取资源
- 世界 Boss：全服协作挑战

## 3. 美术风格

### 3.1 总体基调
- **风格**：2D 等距视角（Isometric），偏卡通/精致写实中间
- **色调**：温暖的中世纪调色板（棕色/金色/绿色为主，魔法用蓝紫色点缀）
- **参考**：江南百景图的布局感 + Darkest Dungeon 的暗色调 + Stardew Valley 的亲和力

### 3.2 建筑风格
- 石材/木材混合结构
- 欧洲中世纪城堡、茅草屋、哥特式教堂
- 魔法建筑有发光/漂浮特效

### 3.3 角色风格
- Q版/半写实
- 每个职业有标志性外观
- 颜色编码：战士红、法师蓝、盗贼绿、牧师金

## 4. 技术架构

### 4.1 客户端（Godot 4）

```
Client (Godot 4)
├── Core/
│   ├── GameManager.gd        # 全局管理器（单例）
│   ├── ResourceManager.gd    # 资源管理
│   ├── BuildingManager.gd    # 建筑管理
│   └── HeroManager.gd        # 英雄管理
├── World/
│   ├── WorldMap.tscn          # 主地图场景
│   ├── TileMap/               # 地形瓦片
│   └── Buildings/             # 建筑节点
├── UI/
│   ├── HUD.tscn               # 顶部状态栏
│   ├── BuildMenu.tscn         # 建造菜单
│   ├── HeroPanel.tscn         # 英雄面板
│   └── ShopMenu.tscn          # 商店
└── Network/
    ├── Client.gd              # WebSocket 客户端
    └── DataSync.gd            # 数据同步
```

### 4.2 后端（Phase 2+）

```
Backend
├── API Server (Go/Node.js)
│   ├── Auth (JWT)
│   ├── Save/Load (cloud save)
│   ├── Social (friends, visits)
│   └── Shop (IAP verification)
├── Database
│   ├── PostgreSQL (account, save data)
│   └── Redis (cache, leaderboard)
└── Admin Panel
    ├── Player management
    ├── Analytics
    └── Event configuration
```

## 6. 开发计划

详见 [GANTT.md](GANTT.md)

### 团队分工
- **Ben（主程）**：Godot 客户端 + 后端 + AI 美术工具链
- **搭档（策划/美术）**：游戏设计 + AI 美术生成 + 测试

### 开发原则
1. **MVP 优先**：先做核心循环，再加内容
2. **可玩优先**：美术可以粗糙，但游戏必须好玩
3. **迭代开发**：每 2 周一个可测试版本
4. **数据驱动**：建筑/英雄数据用 JSON，不硬编码
